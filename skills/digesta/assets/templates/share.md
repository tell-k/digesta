# Slack 投稿文のひな形

<!-- 成果物を社内に共有するときの投稿文。会議ごとに digest/share.md として作り、そのまま貼れる形にする。
     書き方の手引きは skill の SKILL.md「6. 共有文を書く」。作例は assets/examples/study-share.md。
     絵文字は Slack のショートコード(:jack_o_lantern: など)で書く。冒頭の絵文字は開催月の季節に合わせる -->

:<季節の絵文字>: 忙しい人のための <会議名> ダイジェスト :<季節の絵文字2>:

Wiki: <会議の Wiki やチケットの URL(あれば)>
日時:  <YYYY-MM-DD HH:MM-HH:MM>

<M/D(曜)>の <会議名> を、参加できなかった人向けに <動画の尺>の動画と グラレコ1枚にまとめました。<尺>あれば見られる長さです

1. <発表者>「<題名>」
   <内容を1行で。何の話で、何が面白かったか>
2. <発表者>「<題名>」
   <1行>
3. <発表者>「<題名>」
   <1行>

:mega: お知らせ
<連絡事項。次回の日程、募集、交代など。素材で確認できたものだけ>

:clapper: 動画(<尺>) … 発表者本人の声の切り抜き+字幕
:frame_with_picture: グラレコ(1枚) … 全体像をざっと掴みたい人はこちら
:memo: 要約(Markdown) … 詳しく知りたい人向け

※ ダイジェストと議事録は録画と文字起こしから作成しています。内容に誤りがあれば教えてください。
